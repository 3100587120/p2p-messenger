# 双点聊 0.5.8-test

2026-10-01。Android versionCode 23，arm64-v8a。覆盖安装，不要卸载旧版。

## 本轮功能

- Windows 关闭主窗口改为托盘后台运行；托盘可以恢复界面或明确退出。设置内提供开机后台收消息开关，登录后默认启用，用户关闭后不会自动重新启用。托盘退出或电脑关机之后不可能继续接收。
- Android 独立后台消息前台服务保留连接，界面划走不主动停止服务；增加定时续期的 CPU 唤醒锁和电池后台设置引导。不使用 Google 推送，不在后台偷偷打开麦克风。应先登录并允许通知/后台运行。系统强行停止、厂商杀后台、无网仍不能保证即时通知，尚未在安卓真机验收。
- 语音通话使用 Windows 独立可拖动小窗口；安卓使用非模态可拖动浮层，不阻塞聊天打字。关闭通话小窗口只隐藏，聊天工具栏可重新打开；挂断按钮才结束通话。
- 群详情中可以选择好友发送入群邀请，群主/管理员可以移除成员，普通成员不能踢人、管理员不能踢群主或其他管理员。成员变更仅接受群主签发的版本化快照；被踢后旧邀请不能自动恢复群聊。邀请需要对方接受，非群主操作需要群主设备上线同步。当前端到端群聊最多 20 人，并非 QQ 全量功能或中心化群系统；群主转让未实现。
- Windows 文件可拖入当前会话，先显示确认列表，点击单个文件或发送全部才发送。切换会话取消原暂存列表，不误发到另一人。支持本机文件，不支持拖入文件夹或网页。
- 会话工具栏和详情中增加查找聊天记录，可搜索当前/全部本机会话文字及文件名，最多返回 200 条，点击定位原消息。撤回内容不出现在搜索结果中。
- 好友详情显示 UID；群详情显示稳定的 16 位群号。目前群号用于详情展示，不提供按群号查询/加入的服务。
- 打包离线 Noto 彩色 emoji 字体、Qt 文本渲染，不依赖新版安卓系统字体。Windows 默认选择 Qt FreeType 字体后端，修复旧原生后端对该彩色字体只能加载、不能彩色渲染的问题。Windows EXE 资源、窗口和托盘使用应用图标。
- UID 1 与 11、12、13 的关系修复只针对已授权账号，保留账号、密码、备注和记录。中继只存发给各身份的加密修复指令，新版连接后应用一次。已验证本机三个匹配资料修复；安卓资料需要更新新版并联网才应用，尚未验证手机实际应用结果。其他账号不受影响，不重置 UID 计数。

## 使用入口与限制

- 设置 → 后台收消息：安卓开启并按提示允许后台运行；Windows 可以设置开机后台运行。
- 聊天右上角 → 查找聊天记录；好友/群详情 → UID/群号；群详情 → 邀请好友/群成员 → 移除。
- 中继模式仍依赖网络能访问你部署的服务，不承诺国内所有网络免 VPN 可达。
- 对方断网或系统停止应用时，不会伪造“已送达”；未送达消息保留发送端重试。当前没有通用厂商系统推送通道，不能承诺被系统完全停止的安卓程序即时收到消息。

字体来源及授权见 `client-p2p/assets/fonts/README.md`。上一版功能与限制见 `release-0.5.7.md`。
