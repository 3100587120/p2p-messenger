# 双点聊 0.5.9-test：十项任务逐项记录

2026-10-01。按用户给出的顺序实现和核查；不是十项全部完成的发布声明。

## 1. 群聊邀请提醒

- 群邀请进入申请总数、会话列表入口、申请页及已有消息通知通道；显示群名、邀请人、人数和加入按钮。
- 相同邀请重传不重复发新邀请提醒，元数据更新不重复打开申请弹窗。
- 安卓通知仍需要系统通知权限及后台服务正常运行。没有增加厂商推送，系统强行停止应用不保证即时通知。

## 2–3. 布局和视觉层次

- QQ 风格的浅蓝/白色卡片、圆角搜索与输入框、选中会话标识、联系人分组、空态引导、头像占位和在线点。
- 短文本气泡按内容宽度排列，文件卡片按类型区分颜色；会话按最近消息排序，联系人页只展示已建立关系的条目。
- 不照搬 QQ 商标或素材。实际 Windows 原生界面 320/390 竖屏布局回归通过；不等于安卓真机验收。

## 4. 群内非好友显示

- 不再以密钥截断字符串冒充昵称；资料未同步时显示“群成员（资料待同步）”。
- 入群后请求成员资料并发送自身资料。成员资料请求必须来自当前群成员，回复只给请求者。
- 空群名称使用可读的“新群聊”，已同步的昵称、头像和 UID 保留。

## 5. 保存账号

- 账号切换改为头像、昵称、UID 和当前账号状态卡片。
- 从已有加密账号资料读取头像和 UID；头像不另存入公开的 accounts.ini。
- 没有清空、重注册或迁移现有账号。

## 6. 过渡动画

- 弹窗淡入缩放、会话面板切换、消息通知淡入及按钮交互反馈。
- 设置中可关闭过渡动画；目前此开关仅影响本次运行，未做跨启动持久化或系统减少动态效果自动同步。

## 7. 安卓长按

- 统一消息长按入口，窄屏显示底部文字+图标操作面板：复制、转发、撤回、删除本机消息、取消。
- 撤回只对自己发送的消息启用；切换账号/会话关闭旧操作面板。
- 桌面原生竖屏回归验证操作面板和可见按钮，没有声称在安卓真机测试了触摸手势。

## 8. 文件卡片与预览

- 展示文件名、扩展名、中文类型、大小、预览和保存入口。
- 文本预览前 64 KB；图片生成有限尺寸缩略图，限制预览解码内存，不限制文件传输大小。超大图片、PDF、Office、压缩包等显示类型信息并提示保存后使用对应软件，未实现所有格式的应用内内容预览。
- 加密分块文件的预览和已发送原文件复制在工作线程执行。已发送大文件保存不再生成空文件；原文件已移动/改变、目标已存在、权限/空间不足都说明原因。
- 完整文件仍保留原内容；预览截断不改变保存的文件。

## 9. 主中继替换：尚未完成

- 官方核查候选为腾讯 EdgeOne Makers，长期免费计划和香港函数区域见 relay-hosting-review-2026-10-01.md。
- 实际控制台仍显示腾讯云登录页；需要用户完成登录。跨实例投递、账号注册原子性和香港端点验收也尚未完成。
- **客户端当前仍以 Cloudflare 为主，没有实现“香港主服务 + Cloudflare 自动备用切换”。** 不拿 CDN 接入地点冒充中继后台位置，不承诺任何第三方服务永不调整政策。
- 没有启用付费服务，没有修改 UID 分配顺序、密码验证信息或好友备份。

## 10. 远程速度：已优化，尚未彻底解决

- 送达回执建立消息索引，避免每个文件块都读取所有聊天记录。
- 文件按窗口批量入队，ACK 到达后立即推进；闲置时停止文件泵。
- 重试按包类型限频；重新上线通过订阅通知唤醒发送端。重连优先文字/申请，再文件；实时通话时避免批量文件重试占用通道。
- 中继端新增订阅通知已部署到现有 Cloudflare 服务，账号存储绑定保持不变。
- 同机双身份实际公网 WSS 综合测试（私聊、群聊、图片、表情、语音文件、普通文件、3 MB 文件）：优化前一次 158.4 秒，最终构建一次 115.9 秒。最终构建文字首次观察送达 4.52 秒，仍不足以宣称慢的问题解决。
- 上述不是两台独立网络设备，也不是安卓手机实测；没有关闭 TLS 或加密来换速度。
- 同时运行大文件测试和登录压力测试时，登录事件循环出现一次约 579 ms 调度间隔，响应性阈值测试未通过；停止并行压测后单独重测通过。这也说明重负载响应性仍需优化，不能据单独通过宣称所有场景无卡顿。
