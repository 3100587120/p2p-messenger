## 常用操作

1. 账号页创建账号时填写昵称、密码和确认密码；登录已有 UID 时填写 UID 和密码。使用原设备重新登录会在验证身份后复用对应的本机资料，不会清空已有好友。
2. 点击右上角 ＋ 添加好友，填写对方 UID；收到申请后确认。已经添加的好友不能重复发送验证申请。
3. 会话底部 ＋ 打开照片、文件、语音通话、表情等功能；安卓还有拍照，Windows 还有截图预览。麦克风按钮切到“按住说话”，松开发送，上滑后松开取消。
4. 点击头像或通话右侧的详情图标查看资料。群详情可以修改群名称与群头像；删除群聊相当于退出群聊并移除本机列表，不会解散所有成员的群。
5. 长按消息或电脑右键消息可复制、转发、删除本机消息。语音播放后显示“再次播放”，播放中可停止。
6. 安卓“我 → 设置与后台消息”中查看后台收消息及通知状态；按错误弹窗的入口打开系统权限设置。开启通知、允许后台运行，并按手机厂商要求允许自启动/不限制电池。

## 重要边界

默认辅助连接，具体内置地址不在普通首页展示；自定义地址只覆盖本机。需要设备网络能访问辅助服务，纯直连不能保证任意网络连通。

聊天记录只在本机。同一设备重新登录可以恢复其旧好友/历史；登录另一台新设备不会云同步好友和历史。文件上限 2 MB，语音/图片上限约 1.8 MB。

Windows 隔离启动、自动化回归、APK 签名和公开中继转发测试通过。没有安卓真机连接，因此拍照/录音/文件选择、手势返回/切应用、任务划走后的通知不能标作真机验证完成。系统强行停止、杀后台或无网络时不能保证即时收到消息；后台服务不等于厂商推送。后台来电提示未接通，需要回到前台重新呼叫。
