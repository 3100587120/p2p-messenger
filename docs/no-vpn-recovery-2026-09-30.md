- `master-key.protected` 和 `__relay_identity` 文件仍存在。既有身份能用原密钥解锁，已在只读副本测试验证。

- 当前 Workers 地址直接连接超时，使用现有系统代理时 `/health` 返回 200。不要把通过代理的跨网测试当成无 VPN 验收。
- 当前没有连接的真实 Android 设备；不能确认手机网络超时的全部原因。

## 实现与验证

- `LocalVault` 对读取、文件为空、认证/格式错误、备份错误、原子写入错误分别提供具体原因。
- 只对确实为 0 字节的配置尝试恢复，先保留 `.empty-UUID` 原文件，再使用可读加密备份；没有备份时重建默认配置。
- 不重置密钥、身份，不删除聊天文件。0 字节中丢失的名称/好友索引无法凭空恢复；没有有效备份则需重新填写名称、添加好友。
- 保存之前留下上一份可读加密备份；备份失败、加密失败或非空原文件损坏时拒绝覆盖；写入使用原子提交和文件锁。
- 对空的出站队列/去重元数据同样保留空文件后恢复；对非空损坏数据和加密身份不做重置。
- 使用真实用户 vault 文件的**临时副本**运行生产控制器：名称保存、模式切换、重新打开、邀请码身份不变、既有聊天文件不变均 PASS。
- 测试前后原 vault 所有文件的 SHA-256 一致，测试没有修写 C 盘原数据。恢复逻辑要在后续发布版启动后才应用。
- 可自托管中继使用 ws 8.22.0（官方 npm 完整性已核对），复用 Worker 路由；6 项 Node 测试通过。
- 真实 Qt RelayClient 与独立中继在回环网络完成自检、加密好友申请、认证回执、文件大小帧，以及对方晚到后的自动重发测试，均 PASS。
- 独立中继默认只监听回环地址；远程监听必须 TLS。不会自动关闭证书验证、开防火墙、改 DNS 或路由器。

## 登录暂停后的独立修复

用户要求先处理其他工作，因此没有继续尝试 Render 登录、创建资源或打包产品。

- 收到好友申请、好友确认、群邀请时，若账号配置保存失败，回滚内存状态并拒绝回执。不会弹出实际未保存的申请或提前显示可聊天；失败弹窗包含具体存储原因。
- 未确认的好友不能用普通聊天数据自动升级为“已验证”；须处理真实的好友确认。
- 中继的未加密路由状态只能是 `forwarded` 或 `recipient_offline`，且须对应当前发送队列。中继伪造 `delivered` 或未知包状态被忽略；“已送达”只由对方身份的加密回执产生。
- 中继断开时，尚未确认送达的好友条目明确指出本机连接断开；已经收到真实回执的申请保留“对方已收到”，不误降级。
- 附近设备添加成功后的弹窗绑定正确好友，不再显示上一次或空条目的状态。说明文字改为可配置中继，不限定 Cloudflare。
