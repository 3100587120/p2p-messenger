# 双点聊 0.5.6：连接配置修复和自由截图

2026-09-30，安卓 versionCode 21。覆盖安装，不卸载、不清除应用数据。0.5.5 是未交付的中间包。

## 连接问题

确认旧 0.5.4 的 Windows/Android 构建缓存和生成配置中的默认辅助地址为空，旧 APK 的实际程序库也不包含完整默认连接地址。先前公开中继测试显式指定了测试地址，所以未覆盖最终包的默认配置。这是交付漏检，不是用户需要手动配置。

修复：两个产品构建脚本从 relay-deployment.json 读取已部署服务；产品 CMake 拒绝空默认地址，Windows 打包也检查生成配置。普通首页不展示内置地址；自定义服务仍只覆盖本机。本轮没有清空账号或聊天记录，也没有重新部署中继。

新增 Windows 实际交付 EXE 检查命令 --verify-default-relay：强制不使用测试环境地址覆盖，只用临时加密身份，验证默认服务的认证加密往返。不会读取用户凭据、注册 UID 或修改真实账号。已通过本机网络/系统代理测试；Android APK 检查的是程序库内的配置及签名，不是假称安卓真机连接测试。

## Windows 自由截图

- 默认全局快捷键 Ctrl+Alt+A；被其他软件占用时尝试 Ctrl+Shift+A。当前成功注册的组合显示在设置中；都被占用时可用聊天工具中的截图按钮。
- 启动后冻结屏幕，拖动鼠标框选矩形区域，松开完成；Esc 或右键取消。支持向任意方向拖动，以及跨显示器的桌面范围。
- 选区复制到剪贴板，并打开预览。仅确认“发送截图”后才发给当前会话，没有定时采集或自动上传。
- 切换账号取消未完成的截图，不把旧账号的截图送到另一个账号；没有会话时仍可截图复制，但不能发送。
- 本轮裁剪回归覆盖反向拖动、边界裁剪和过小选区；未自动截图用户桌面来测试交互，也尚未在不同 DPI 多屏桌面实测。
