# 双点聊 0.5.7-test 实现与验证记录

2026-09-30。Android versionCode 22。此版是测试版，不将桌面自动化结果冒充安卓真机验收。不删除现有账号、好友或聊天记录。

## 本轮实现

- 好友设置：备注、置顶、消息免打扰、清空本机记录、删除好友。默认名称仍使用对方资料；备注仅本机生效。
- 群聊设置：群公告、群成员与管理员入口、群名称/头像、置顶、免打扰、退群；公告和群资料要求群主/管理员，管理员任免仅群主。不是 QQ 全功能复制，群主转让、禁言和完整审核机制尚未实现。
- 会话显示最新消息、时间、未读数字；免打扰不丢消息，只抑制提醒。文字可拖选，表情直接发送；头像可以放大查看。
- 新消息支持两分钟内撤回。仅限新版本带消息 ID 的自己的消息；不能收回别人已复制或另存的内容。
- Windows 更换短双音提示，避免系统气泡再次发声。实际扬声器听感未验收。
- UID 密码派生和身份解密离开 GUI 线程；取消、重复响应、切换账号和销毁旧连接有隔离保护。修复连接销毁时定时器已销毁仍被信号访问的问题。
- 同机登录复用原身份资料；新增端到端加密的好友/群元数据备份（不上传聊天内容），支持之后卸载重装的身份恢复。旧账号需在仍保留资料的设备密码登录并成功同步；已经丢失且从未备份的好友不能凭空恢复。恢复失败会阻止空资料覆盖云端备份。
- 通话窗口不再阻塞打字，增加时长记录；群通话协议最多六人，重放/序号校验、混音和超时离开；复用 Speex 回声消除。实际多人通话、回音改善待设备验证。
- 安卓增加通话专用前台服务，接通后后台继续持有会话；后台来电保存有效邀请并通过通知打开应用接听。没有自动开启麦克风；强行停止、无网、系统杀后台不能保证收到来电。实际后台录音及接听待设备验证。
- 超过 2 MB 的文件改为独立加密分块传输/异步保存，不整文件读入内存；无人为固定总大小上限，但受剩余空间、网络和平台能力约束。照片预览仍压缩，原始大图可按文件发送。
- 安卓返回/恢复窗口的渲染生命周期调整；黑屏、相机、相册、通知弹出及 emoji 字体仍须真机检验。

## 已执行的回归

- 服务端账号目录、授权与加密备份单元测试 10/10 通过；服务端已部署。
- 密码错误、密钥替换、密文篡改、持久化和备份损坏测试通过。
- 六种异步登录/注册场景通过：成功恢复好友备份、取消、销毁、错误密码、注册和旧会话不再写入。
- QML 320/390 像素和桌面布局、登录字段、窗口保留检查通过。
- 私聊/群聊分类、头像详情、撤回权限、公告权限、免打扰、记录保留、后台单写者交接、录音停止与通话协议测试通过。
- 3 MB 分块文件乱序/重复、加密保存、导出和取消的本地协议测试通过。
- 公网 WSS 私聊/群聊文字、头像资料、照片、表情、语音文件、小文件及 3 MB 分块文件测试通过。分块文件在 120 秒窗口未完成，扩大至五分钟窗口后通过；这证明完成与接收，不证明速度已达标，吞吐优化仍待继续。
- Windows/Android 编译通过。没有连接安卓真机，公网测试客户端也在同一台电脑，不能代替两台异网设备测试。
