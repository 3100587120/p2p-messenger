# UID 与语音界面改造状态（2026-09-30）

## 已实现的代码

- 新账号默认辅助连接；保留已保存的连接模式选择，连接设置独立入口。
- 普通界面隐藏内置中继地址，自定义地址只保存在本机，换服务后重新领取该服务的 UID。
- 本机多账号、独立密钥与加密记录；免手机号/邮箱创建昵称并联网注册数字 UID。
- 中继公共账号目录持久化，普通顺序编号从 11 起，重复注册不换号。
- 此电脑专用凭据经过 HMAC 验证后领取剩余的 1–10；用完后进入普通顺序。资格凭据不在客户端包中，只在服务器 Secret 和此电脑的加密库中。
- UID 查找后通过原有加密好友申请/接受及设备回执建立聊天关系。
- 蓝白浅色界面、手机紧凑聊天头部和发送栏、可滚动账号设置、安卓键盘调整窗口尺寸。
- 本机头像上传与私聊好友头像更新，限制图片大小/尺寸并校验解码。
- Unicode 表情、自定义静态表情图片、最多 50 个本机加密收藏、长按删除。
- 群内昵称独立保存，发送群消息时传递昵称。
- 私聊/群聊语音消息，最长 60 秒，16 kHz 单声道 PCM，加密分块传输并本机保存。
- 私聊语音通话，显式接听后才请求麦克风；端到端加密、会话/序列验证、不加入离线队列，挂断/断线/进入后台停止麦克风。

## 验证边界与阻点

- C++ 隔离回归：身份持久化、0 字节配置恢复、失败写入、好友送达不能被中继元数据伪造。
- 新功能隔离回归：头像、群昵称、表情发送/收藏、群语音分块存储、多账号独立密钥、来电不自动开麦克风。
- QML 桌面与竖版加载无警告，320/390 宽度聊天返回、文件、输入、发送控件检查均在窗口内。物理安卓键盘、麦克风/扬声器效果和真实双机通话尚未实测。
- Node 目录测试：从 11 顺序分配、重复注册、预留号防伪、前 10 个主人账号后转普通号；原有 WebSocket 路由测试通过。
- Cloudflare CLI 已经用户授权，登录凭据加密文件在 D 盘，钥匙在 Windows 凭据管理器中。
- 现有中继已更新，版本 `09d03bdf-2ff4-4c23-958f-92042d267d5c`。
- 线上一次性普通测试账号注册/UID 查询通过（显式代理路径，分配 UID 11）。这是 QA 注册，不是主人账号，不占用 1–10。
- 当前机器不使用显式代理连接该中继时 WebSocket 握手超时。不能声称国内免 VPN 已解决，更不能把同机/回环测试当作异网成功。
- 预留号凭据经本机代理发送的验证被自动审核拦截；只允许在用户明确授权该代理承载 TLS 加密注册请求后继续此项，不得换通道绕过。
- 用户随后选择“暂不绑定预留 UID”；客户端对已配置主人资格的电脑暂停目录注册，只有单独明确启用才能发送预留号申请。不能在测试/自动重连时偷偷领取或给这台电脑先分配普通 UID。
- 用户随后明确“不用非得免 VPN”：解除免 VPN 作为打包前置条件，允许交付依赖 VPN/代理可达辅助服务的测试包。这不解除预留 UID 暂缓绑定的决定。
- 两个临时 C++ 客户端经过真实公网 WSS 中继和当前系统代理，普通 UID 12/13 注册、按 UID 查询/申请、接收/接受、双向加密文本均通过。不使用局域网传输，但两个客户端在同一测试主机，不能冒充安卓/电脑异网实机验收。
- 安卓 0.5.0-test（versionCode 15）本地构建通过，APK 包含 Qt Multimedia、音频插件和 OpenSSL 3；Windows 包补齐 multimedia 插件。
- 测试包不是“全部实机验收完成”：尚无真实安卓与电脑跨网互通/语音设备效果结果。
